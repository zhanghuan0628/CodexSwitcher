# 登录失效后重绑卡住修复

- 变更背景：登录失效后重新登录并绑定成功，界面可能长时间停在“登录中/绑定中”，需要杀掉应用后才恢复。
- 本次变更内容：Codex CLI 登录态探测、CLI 路径解析和打开官方登录流程增加 8 秒超时；手动采样和托盘采样改为网络采样期间不持有数据库锁。
- 涉及范围：Mac 端官方账号登录、重绑、刷新状态、立即采样和托盘采样。
- 是否影响配置：否。
- 是否影响接口或使用方式：否，用户操作入口不变。
- 是否向后兼容：是。
- 验证方式：`cargo check`、`cargo test`、`npm run build`。
- 风险与注意事项：如果 Codex CLI 本身超过 8 秒仍无响应，本次会返回超时错误，避免界面无限等待。
