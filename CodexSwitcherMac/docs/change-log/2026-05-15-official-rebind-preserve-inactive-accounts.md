# 官方账号重绑保留非当前账号状态

- 变更背景：用户重新登录并绑定新的官方账号后，旧账号会在后台采样中被写成“登录失效”，看起来像被新绑定账号顶掉。
- 本次变更内容：非当前官方账号在后台或批量采样中遇到绑定快照暂不可读时，不再直接写入 `auth_invalid / expired`；只记录一次警告通知并保留上一次可信状态。当前活跃账号遇到明确授权失效时仍会标记为登录失效。
- 已有数据自愈：读取账号列表时，如果非当前账号已经被误写成登录失效，但本地 Keychain / 会话快照身份仍匹配且存在真实用量快照，会恢复为上一次可信风险状态。
- 涉及范围：Mac 端官方账号绑定、后台采样、立即采样、账号列表状态展示。
- 是否影响配置：否。
- 是否影响接口或使用方式：否，按钮和命令不变。
- 是否向后兼容：是。
- 验证方式：`cargo test auth_invalid_sampling`、`cargo test query_accounts_recovers_inactive_auth_invalid_when_bound_snapshot_is_trusted`，以及后续完整 `cargo test` / `npm run build` / `tauri build`。
- 风险与注意事项：非当前账号的真实授权是否仍可用，会在切换到该账号或重新登录该账号时再次做强校验。
