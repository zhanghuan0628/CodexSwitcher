# 后台刷新与 Key 身份下官方采样修复

- 变更背景：应用每隔十几秒出现鼠标转圈和短暂不可操作；当前运行身份为第三方 Key 时，官方账号额度与恢复时间无法通过采样或刷新状态更新。
- 本次变更内容：前端自动刷新只同步轻量状态，不再每轮拉第三方 Key 用量；默认自动采样间隔从 15 秒调整为 60 秒；手动“刷新状态/立即采样”会采样所有官方账号；官方账号采样在当前为 Key 身份时改用账号绑定快照读取真实额度。
- 涉及范围：Mac 端自动刷新、后台自动采样、手动刷新状态、立即采样、官方账号额度和恢复时间展示。
- 是否影响配置：会把旧默认 15 秒或 120 秒自动采样间隔迁移为 60 秒；用户仍可在设置页手动调整。
- 是否影响接口或使用方式：操作入口不变，“刷新状态”现在会触发一次官方账号真实采样。
- 是否向后兼容：是。
- 验证方式：`cargo check`、`cargo test`、`npm run build`。
- 风险与注意事项：手动刷新会访问真实额度接口，网络慢时按钮会短暂进入处理中；后台自动刷新不再发起第三方 Key 用量请求，Key 用量仍会在启动、保存或手动采样后刷新。
