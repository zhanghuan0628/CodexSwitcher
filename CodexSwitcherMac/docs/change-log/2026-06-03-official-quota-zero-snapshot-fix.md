# 官方账号额度 0/0 快照修复

- 变更背景：官方账号列表中，额度有时会在自动刷新或后台采样后显示为 `0% / 0%`，手动点击“立即采样”后又恢复为真实额度。
- 本次变更内容：账号列表、概览和详情统一读取最新可信真实快照；真实额度接口响应缺少 5h 或 7d 百分比，或窗口时长为 `0` 时，本轮采样视为不可读，不再写入 `0%` 快照；启动时会清理历史中 `secondary_window: null` 的坏 `0% / 0%` 快照。
- 涉及范围：Mac 端官方账号额度展示、后台采样、手动采样后的快照读取。
- 是否影响配置：否。
- 是否影响接口或使用方式：否，按钮和前端字段保持不变。
- 是否向后兼容：是；历史可信真实快照仍会继续展示。
- 验证方式：`cargo test`；覆盖安装 `/Applications/CodexSwitcherMac.app` 后启动并检查本地库，坏 `0% / 0%` 快照计数为 `0`。
- 风险与注意事项：如果真实额度接口临时返回不完整数据，界面会保留上一条可信真实快照或显示未知，不再用缺失值冒充 `0%`。本次问题还暴露出 release bundle 路径与 `/Applications` 安装路径可能混用，重启时应确认运行进程来自 `/Applications/CodexSwitcherMac.app`。
