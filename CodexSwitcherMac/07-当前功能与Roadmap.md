# CodexSwitcher Mac 当前功能与 Roadmap

更新时间：2026-04-19

## 1. 当前定位

CodexSwitcher Mac 当前定位为：面向 Codex 重度用户的本地真实账号调度与接力工作台。

产品原则：

- 只走 Codex 官方登录态，不接入 Claude 或其他供应商登录作为主路径。
- 不生成演示账号、假快照或本地推断数据冒充真实额度。
- 账号切换必须用户确认；自动化只做刷新、采样、提醒和接力辅助。
- 5h 或 7d 任一窗口已用达到 100% 时，账号即判定为不可用。

## 2. 已完成功能

### 2.1 官方登录与绑定

- 支持打开 Codex 官方登录流程。
- 支持读取当前官方登录态的登录邮箱和官方账号 ID。
- 支持绑定当前已登录账号。
- 支持重复绑定保护，避免同一官方账号被重复写入多张卡。
- 支持登录态不一致时禁止校验，避免误覆盖账号。

### 2.2 多账号中心

- 支持真实账号列表。
- 支持默认账号、当前活跃账号、真实绑定状态展示。
- 支持按当前登录态重新绑定。
- 支持登录失效账号的一键重新登录并等待自动重绑。
- 支持账号详情增强：最近采样、最近切换、Keychain 状态、绑定快照、失败原因、健康时间线、诊断复制。

### 2.3 真实采样与自动化

- 支持真实用量采样。
- 支持 5h 已用、7d 已用、5h 预计恢复、7d 预计恢复展示。
- 支持关闭窗口后保持 Menubar 后台自动采样。
- 支持采样失败退避和通知。
- 支持即将恢复提醒。

### 2.4 切换与接力

- 支持用户确认后真实切换。
- 支持切换前校验目标账号状态。
- 支持切换失败回滚。
- 支持切换成功后自动采样。
- 支持切换接力卡。
- 支持接力卡模板：切换接力、排障接力、功能开发接力。

### 2.5 仪表盘与分析

- 支持当前活跃账号总览。
- 支持多账号状态列表。
- 支持使用趋势图基础视图。
- 支持趋势摘要：最近最高已用、预警次数、切换次数。
- 支持账号时间轴基础视图。
- 支持预警状态下半自动切换提示。

### 2.6 通知与发布测试

- 支持通知中心展示登录、绑定、校验、修复、切换、系统事件。
- 支持通知按类型筛选。
- 支持通知按账号筛选。
- 支持通知跳转账号详情。
- 支持发布前诊断和历史调试数据清理预览。

## 3. 当前仍待完善

### P0：稳定性和工程结构

- Rust 后端仍集中在 `src-tauri/src/lib.rs`，需要拆成模块。
- 需要继续补充真实登录、切换、采样、Keychain 和后台采样的回归测试。
- 需要增加启动健康检查，防止 UI 初始化与后台任务互锁。

### P1：产品闭环

- 登录向导已出现六步状态，但还可以升级为更强的向导式流程。
- 账号详情已增强，但可以继续加入导出诊断包。
- 通知中心可以增加批量清理旧通知。
- 恢复提醒可以支持点击后直接定位到账号卡。

### P2：智能调度

- 时间轴可继续升级为 3h / 6h / 12h 可切换范围。
- 推荐引擎可继续综合恢复时间、最近切换频次和失败次数。
- 接力卡可继续自动读取 Git diff 和最近命令。

### P3：长期方向

- Menubar Mini Dashboard。
- 诊断包导出。
- 更细粒度本地审计日志。
- 模块化后的独立服务测试。

## 4. 已知风险

- Codex 官方登录态和用量接口可能变化，需要保守处理错误。
- 真实用量读取失败时必须展示未知，不允许补假数据。
- 自动切换不建议直接无感上线，应继续保持用户确认。
- 后台采样和托盘刷新必须避免持有数据库锁时触发 UI 更新。

## 5. 下一步建议

建议下一阶段优先做：

1. 拆分 Rust 模块第一批：`auth`、`accounts`、`usage`、`tray`。
2. 增加启动健康检查和 UI 白屏防回归。
3. 完善时间轴范围切换和推荐理由。
4. 增加通知清理和恢复提醒跳转。
5. 继续补真实链路测试。
