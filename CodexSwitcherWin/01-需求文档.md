# CodexSwitcher Win 需求文档

## 1. 项目背景

Windows 端用户在使用多个 Codex/ChatGPT 账号时，也存在和 Mac 端相似的问题：

- 当前账号额度状态不透明
- 切换账号过程繁琐
- 切换后上下文断层明显
- 多账号调度决策依赖人工记忆

本项目目标是提供一个适合 Windows 使用习惯的本地账号调度工具，核心仍然是：

- 额度可视化
- 一键切换
- 会话接力
- 官方扩容优先

## 2. 产品目标

- 帮助用户实时感知多个账号健康状态
- 用更低操作成本完成切换
- 在切换过程中保留工作上下文
- 给出清晰推荐而不是直接推动频繁切号

## 3. 非目标

- 不做平台限制规避器
- 不做共享账号市场
- 不承诺后台完全无感自动切换
- 不依赖单一不稳定隐式接口

## 4. 核心功能范围

## 4.1 首页仪表盘

- 展示当前活跃账号
- 展示账号总览与风险等级
- 展示推荐动作
- 展示最近接力入口

## 4.2 多账号管理

- 添加、删除、编辑账号
- 默认账号设置
- 登录状态修复
- 最近检测状态查看

## 4.3 额度检测

- 5h / 7d 窗口状态展示
- 24h / 3d / 7d 历史趋势图
- 预警点、恢复点、切换事件展示

## 4.4 一键切换

- 目标账号可用性校验
- 切换执行
- 切换后校验
- 失败回滚
- 日志记录

## 4.5 会话接力

- 支持切换前生成接力卡片
- 展示最近修改文件
- 展示最近命令
- 输出建议续接 Prompt

## 4.6 账号时间轴

- 展示未来 3h / 6h / 12h 可用性
- 展示推荐下一切换时机
- 展示推荐切换路径

## 4.7 官方扩容优先

- 阈值触发时优先提示官方扩容方案
- 再展示备用账号建议

## 5. 目标用户

- Windows 主力开发者
- 使用 Codex CLI / ChatGPT 较频繁的工程师
- 同时管理多个账号、需要提升调度效率的用户

## 6. Windows 平台特性要求

- 首页以主窗口为核心，不强依赖 Menubar 形态
- 支持托盘图标作为快速入口
- 兼容 Windows 10/11 常见显示缩放
- 敏感信息不得明文存储
- 通知、开机自启、后台驻留要符合 Windows 用户习惯

## 7. UI 风格与设计规范

### 7.1 设计定位

Windows 版 UI 需要继承整体产品风格：`简洁大方、小清新、轻量效率工具感`。  
但不能简单照搬 Mac 原生观感，需要更适配 Windows 常见应用的窗口、托盘、列表和设置页使用习惯。

参考方向：

- `awesome-design-md`
- `Cal.com` 风格的清爽结构
- `Notion` 风格的柔和层次
- `Linear` 风格的精细间距

### 7.2 视觉关键词

- 浅色
- 克制
- 高信息密度但不拥挤
- 工具感
- 清爽

### 7.3 禁止项

- 不做重科技风大屏
- 不做高饱和霓虹渐变
- 不做厚重拟态或复杂装饰
- 不做只适合 Mac 的窄标题栏视觉

### 7.4 色彩规范

- 页面背景：`#F7FAF8`
- 主卡片背景：`#FFFFFF`
- 次级背景：`#F1F6F4`
- 主文字：`#1F2A24`
- 次文字：`#5F6B66`
- 描边：`#E3ECE8`
- 主色：`#58C2A8`
- 信息蓝：`#6FAFEF`
- 预警黄：`#F2C66D`
- 危险红：`#E97B73`

### 7.5 字体与层级

- Windows 优先使用系统无衬线字体
- 维持统一层级：
  - H1：28/34，600
  - H2：22/28，600
  - H3：18/24，600
  - Body：14/22，400
  - Meta：12/18，500

### 7.6 首页结构要求

首页第一屏顺序固定为：

1. 当前活跃账号总览卡
2. 多账号状态总览卡
3. 用量历史图表
4. 账号时间轴视图
5. 推荐动作卡

### 7.7 托盘结构要求

托盘展开后必须包含：

- 当前活跃账号
- 当前状态与百分比
- 快速切换入口
- 推荐动作
- 打开主窗口入口

### 7.8 图表与组件规范

- 历史图表支持 `24h / 3d / 7d`
- 时间轴支持 `3h / 6h / 12h`
- 图表折线宽度 3px
- 预警点、恢复点、切换事件需要有清晰视觉区分
- 推荐卡片一次最多显示 3 条建议

## 8. 信息架构

- 首页仪表盘
- 账号中心
- 接力中心
- 通知中心
- 设置中心
- 托盘快捷入口

## 9. MVP 范围

### P0

- 主窗口仪表盘
- 账号管理
- 检测能力
- 一键切换
- 接力卡片
- 托盘快捷入口

### P1

- 历史图表
- 推荐账号
- 切换日志
- 通知中心

### P2

- 时间轴视图
- 高峰时段识别
- 智能推荐路径

## 10. 验收标准

- 可稳定管理 2~5 个账号
- 账号状态在首页清晰可见
- 可完成切换闭环并提供失败回滚
- 接力卡片可保存、查看、复制
- 历史图表和时间轴功能具备可演示价值

## 11. 风险与注意事项

- Windows 托盘、通知、凭证安全与 Mac 实现方式不同
- 账号状态口径可能变化，页面必须展示“估算”标签
- 自动化程度越高，维护和合规风险越大
