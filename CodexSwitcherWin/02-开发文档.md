# CodexSwitcher Win 开发文档

## 1. 技术方案概述

建议采用：

- 桌面端：`Tauri + React + TypeScript`
- 本地服务：`Rust`
- 数据存储：`SQLite`
- 凭证存储：Windows Credential Manager 或加密存储封装
- 图表：`ECharts`

这样做的好处是：

- 与 Mac 端保留较高代码复用率
- 统一前端组件与业务模型
- 平台差异主要收敛在系统能力层

## 2. 架构原则

- 跨平台共用业务模型
- 平台能力分层隔离
- 前端组件高度复用
- 切换逻辑、状态机、数据库结构尽量统一

## 3. UI 开发规范

### 3.1 设计参考

- `awesome-design-md`
- `Cal.com`：结构清爽、层级克制
- `Notion`：柔和留白与卡片关系
- `Linear`：精细间距与高可读性

### 3.2 视觉主题

- 默认浅色
- 简洁大方、小清新
- 保持 Windows 工具软件气质
- 既统一整体品牌，也适配 Windows 用户习惯

### 3.3 样式令牌

- 背景：`#F7FAF8`
- 主 Surface：`#FFFFFF`
- 次 Surface：`#F1F6F4`
- 主文字：`#1F2A24`
- 次文字：`#5F6B66`
- 主色：`#58C2A8`
- 预警：`#F2C66D`
- 危险：`#E97B73`
- 描边：`#E3ECE8`

### 3.4 必备组件

- `StatusTag`
- `MetricCard`
- `AccountCard`
- `ChartCard`
- `TimelineLane`
- `RecommendationCard`
- `TrayQuickPanel`

### 3.5 页面规范

首页首屏固定为：

1. Active Account Overview
2. Multi-Account Summary
3. Usage History Chart
4. Account Timeline
5. Recommendation Card

### 3.6 交互动效

- 过渡时长控制在 150ms ~ 220ms
- hover 以轻微阴影/边框变化为主
- 禁止夸张弹跳和高噪声动画

### 3.7 禁止项

- 不做赛博霓虹风
- 不做厚重玻璃拟态
- 不做高饱和紫色主题
- 不做只适合 Mac 的窄栏式 UI 结构

## 5. 平台差异实现

### 4.1 托盘替代 Menubar

Windows 端建议：

- 主窗口为主
- 托盘为辅

托盘需支持：

- 当前账号状态
- 快速切换
- 打开主窗口
- 退出程序

### 4.2 凭证存储

- 优先使用系统安全存储
- 若封装层需要落盘，必须进行本地加密
- SQLite 不保存明文凭证

### 4.3 系统通知

- 封装 Windows 通知能力
- 首次启动时引导开启
- 失败时要有应用内通知兜底

## 6. 核心模块

### 5.1 Account Manager

- 账号增删改查
- 当前活跃账号管理
- 默认账号设置
- 状态机维护

### 5.2 Usage Monitor

- 定时采样
- 结果解析
- 快照写库
- 风险等级计算

### 5.3 Switch Orchestrator

- 切换前校验
- 切换动作执行
- 切换后校验
- 失败回滚

### 5.4 Handoff Generator

- 读取上下文信息
- 生成卡片
- 保存与展示

### 5.5 Recommendation Engine

- 推荐下一账号
- 推荐切换时机
- 推荐官方扩容动作

## 7. 数据库设计

与 Mac 端保持一致，建议统一以下表：

- `accounts`
- `usage_snapshots`
- `switch_logs`
- `handoff_cards`
- `app_settings`
- `notifications`

## 8. 页面拆分

### 首页仪表盘

- 活跃账号卡
- 多账号总览
- 用量历史图表
- 时间轴视图
- 推荐动作卡

仪表盘要求：

- 图表支持 `24h / 3d / 7d`
- 时间轴支持 `3h / 6h / 12h`
- 推荐动作卡最多显示 3 条动作

### 账号中心

- 列表
- 详情抽屉
- 添加账号弹窗

### 接力中心

- 卡片列表
- 详情页
- 复制/编辑/用于切换

### 设置中心

- 阈值设置
- 检测频率
- 官方扩容优先
- 托盘行为
- 开机启动

## 9. 接口草案

### 获取账号列表

```http
GET /accounts
```

### 获取仪表盘概览

```http
GET /dashboard/overview
```

### 切换账号

```http
POST /accounts/switch
```

### 生成接力卡片

```http
POST /handoff/generate
```

### 获取时间轴推荐

```http
GET /timeline/recommendation?range=6h
```

## 11. 开发注意事项

- 避免页面只按 Mac 视觉设计，需适配 Windows 常见窗口风格
- 托盘和主窗口要保持状态一致
- 预测类能力必须显示可信度标签
- 首版以“稳定可切换、可追踪”为主，别过早追求复杂自动化
